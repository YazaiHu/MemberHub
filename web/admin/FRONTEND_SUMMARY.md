## 设计特色

### 1. 视觉设计
- **渐变色设计**: 登录页、统计卡片使用渐变色
- **图标系统**: 统一使用 Element Plus Icons
- **颜色标识**:
  - 积分：红色 (#f56c6c)
  - 余额/金额：绿色 (#67c23a)
  - 赠送：橙色 (#e6a23c)

### 2. 交互设计
- **卡片悬浮**: hover 时上移并增加阴影
- **状态标签**: 使用不同颜色区分状态
- **确认对话框**: 敏感操作需二次确认
- **表单验证**: 实时验证用户输入

### 3. 布局设计
- **侧边栏**: 固定宽度 200px，深色主题
- **主内容区**: 自适应宽度，浅色背景
- **卡片间距**: 统一使用 20px gutter
- **表格固定列**: 操作列固定右侧

## 数据流设计

```
用户操作 → 组件事件 → API调用 → Axios拦截器 → 后端API
                                    ↓
                                 响应拦截
                                    ↓
                            成功/错误提示
                                    ↓
                              更新界面数据
```
